## 🏃‍♂️ Início Rápido (Colocando Essa Belezinha Pra Rodar)

### Pré-requisitos

Certifique-se de ter estes instalados (ou prepare-se para um mundo de sofrimento):

- Ruby 3.4.0+ (verifique com `ruby --version`)
- Node.js 22+ (porque JavaScript não vai embora)
- Yarn

### Instalação

1. **Clone esta obra-prima:**
   ```bash
   git clone https://github.com/kszinhu/new.kszinhu.dev.git
   cd new.kszinhu.dev
   ```

2. **Instale as gems do Ruby:**
   ```bash
   bundle install
   ```

3. **Instale as dependências JavaScript:**
   ```bash
   yarn install
   ```

4. **Configure o banco de dados:**
   ```bash
   rails db:create
   rails db:migrate
   rails db:seed  # Opcional: adiciona dados fictícios pra você não ficar encarando páginas vazias
   ```

5. **Ligue os motores:**
   ```bash
   bin/dev
   ```

6. **Visite a mágica:**
   Abra seu navegador e vá para `http://localhost:3000`

*Se tudo funcionou, parabéns! Se não, bem-vindo ao debugging - o café tá na cozinha.*
