## 🎯 About This Project

This is my personal website where I share:

- **📝 Blog Posts**: My adventures in code, war stories, and occasional philosophical rants about why semicolons are optional in Life but mandatory in Rust
- **📖 Handbooks**: Technical guides that I wish existed when I was crying over documentation at 3:07 AM (illumination hour)
- **💼 Career Journey**: The rollercoaster ride of my professional life (spoiler: it's been wild)

Built with Ruby on Rails because sometimes you need a framework that just *gets* you, and Vite because waiting for webpack to compile is so last decade.

## 🏃‍♂️ Quick Start (Getting This Bad Boy Running)

### Prerequisites

Make sure you have these installed (or prepare for a world of pain):

- Ruby 3.4.0+ (check with `ruby --version`)
- Node.js 22+ (because JavaScript won't go away)
- Sqlite
- Yarn

### Installation

1. **Clone this masterpiece:**
   ```bash
   git clone https://github.com/kszinhu/new.kszinhu.dev.git
   cd new.kszinhu.dev
   ```

2. **Install the Ruby gems:**
   ```bash
   bundle install
   ```

3. **Install the JavaScript dependencies:**
   ```bash
   yarn install
   ```

4. **Setup the database:**
   ```bash
   rails db:create
   rails db:migrate
   rails db:seed  # Optional: adds some dummy data so you don't stare at empty pages
   ```

5. **Fire up the engines:**
   ```bash
   bin/dev
   ```

6. **Visit the magic:**
   Open your browser and go to `http://localhost:3000`

*If everything worked, congratulations! If not, welcome to debugging - coffee is in the kitchen.*
